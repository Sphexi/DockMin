What a call does

  • A call starts one run of the automation. It carries no settings: the body and any query string are ignored or refused.
  • A call that arrives while a run is waiting joins it; a call during a run starts one more run after it, at least a minute after the previous one started.
  • Anyone holding the URL can start this automation.
