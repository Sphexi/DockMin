Reconstruct from the cluster

dockmin writes the stack's file from the specifications of its services, networks, configs and secrets. Secret values cannot be read, so each secret is referenced by name. You review the result before anything is stored, and adopting it as is changes nothing on the cluster.

Paste the file

The cluster does not keep the file the stack was deployed from. Paste the file, with the variables it needs. Adopting stores them and puts the stack under your control; it changes nothing on the cluster. The first redeploy then brings the objects in line with the file: every service is updated, which replaces its running tasks, and configs and secrets that the Docker command line named are replaced and removed. The redeploy confirmation names each one.
