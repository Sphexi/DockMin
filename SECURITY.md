# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting: [Report a vulnerability](https://github.com/Sphexi/DockMin/security/advisories/new). The report is visible only to those with access to the repository's security advisories, and creates no public issue.

| Include | Detail |
|---|---|
| Version | The product version and the image tag |
| Description | What was done and what happened |
| Reproduction | The steps, or a minimal configuration |
| Impact | What an attacker gains, and what access they need |

- Do not open a public issue or pull request for a vulnerability.
- Do not include a real encryption key, credential or archive in a report.

## Security model

Roles, authorisation, encryption at rest, outbound contacts and the other protections are described in [Security reference](https://github.com/Sphexi/DockMin/wiki/Reference-Security).
